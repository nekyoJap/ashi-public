# ashi-public

競輪のレース情報・結果を掲載する静的サイト。

| ページ | ファイル |
|--------|---------|
| トップ | `index.html` |
| 飛びつきチャンネル | `channel.html` |
| レース情報（出走表） | `race.html` |
| レース結果（ログイン後） | `result.html` |
| ログイン（仮） | `login.html` |
| 運営会社 | `company/index.html` |

## 共通アセット

`channel.html` / `race.html` / `result.html` は共通デザインシステムを利用しています。

- `assets/keirin-ui.css` — 共通スタイル（白基調＋ネイビー・赤アクセント、グレードバッジ、車番7色、高密度テーブル、固定列）
- `assets/keirin-ui.js` — 共通ユーティリティ（`KUI`）。日付操作・データ取得・バッジ描画・ライン表示・共通ヘッダー／フッター

`index.html` も共通デザインシステムを使います（Tailwind CDN の読み込みはやめました）。
`company/index.html` のみ独立したデザインで、ダークモードは Tailwind の `dark:` で個別に指定しています。

### キャッシュ対策（`?v=`）

GitHub Pages はファイルを10分キャッシュさせる（`Cache-Control: max-age=600`）。HTML と
`keirin-ui.js` が食い違うと、古いスクリプトに無い関数を呼んで画面が止まるため、HTML から
読む `keirin-ui.css` / `keirin-ui.js` には `?v=日付` を付けている。**共通アセットを変えたら
全ページの `?v=` を更新すること。**

それでもスクリプトが読めなかったときは、`race.html` / `result.html` は「読み込み中…」で
止まらず、再読み込みを促すメッセージを出す（`index.html` も同じ）。

### 白基調とダークモード

ライトは白基調（地・ヘッダー・表見出し・フッターとも白〜ごく薄いグレー、区切りは線）。
ダークモードは端末の設定（`prefers-color-scheme`）に追従し、ヘッダー・表見出し・フッターは
ネイビー地のままです。色は `keirin-ui.css` の `:root` と `@media (prefers-color-scheme: dark)` の
2箇所にまとまっています。ヘッダー・表見出し・フッターの色は `--header-*` `--thead-*` `--footer-*`
で指定しているので、ページ側で `var(--navy)` や `#fff` を直接書かないこと。

`:root` の `color-scheme: light dark` は必須です。これが無いと
`<input type="date">` や `<select>` のネイティブ部分、スクロールバーが
ダークモードでも白いまま残ります。

車番7色とグレードバッジは競輪で意味の決まった色なので、暗い配色でも変えていません。

### コメント列の幅

コメント・脚ログ・レース後コメントは `.txt--note` で同じ幅に固定しています。
`min-width` だけでは下限にしかならず、内容の長い方が伸びて幅が食い違うため、
`min/max/width` を同値で持たせています。**列幅はヘッダを含む全セルの最大値で
決まるので、`<th>` にも当てる必要があります。**

幅を固定すると長いコメントが3行以上に伸びて行高が増えるため、
`.clamp2` で折り返しを2行までに抑え、全文は `title` 属性に入れています。

### 固定列

横スクロールする出走表・結果表では、左端の識別列を固定しています。
仕組みは `keirin-ui.css` の `.frz` にあり、列の幅と位置は各ページ側で
`--frz-left` と `min/max-width` を指定します。

| ページ | 固定する列 |
|--------|-----------|
| `race.html` | 車番・選手名 |
| `result.html` | 着順・車番・選手名 |

## トップの開催カード一覧（`index.html`）

WIN KEIRIN アプリのトップを見本にした、開催ごとのカード一覧です（2026-09-27）。

| 左 | 中 | 右 |
|---|---|---|
| 場名・グレード・ガールズ（♥）・日目 | 次に発走するレース番号。全レース終了なら「終了」 | 「脚評価を見る」→ `race.html` のそのレース。終了した開催は「結果」→ `result.html` |

- 日付は出走表と同じ既定（日本時間22時以降は翌日）。`?date=YYYY-MM-DD` と前日・翌日ボタンで切り替え
- 発走前の開催を上、終了した開催を下に並べる
- 見本にある発走時刻・締切までの時間・ナイター等のアイコンは出していない（GCS のデータに発走時刻が無いため）。
  ガールズはレース名が「L級」のレースがあるかで判定
- 「次のレース」は `race.html` と同じ判定（`KUI.nextRaceNum`）。結果 JSON が置かれるまでは 1R になる

## 本番アプリ（asilog-project）から移した画面の機能

本番アプリ（`asilog-project` の Next.js 版）で作った画面の機能のうち、静的サイトでも動くものを移しています。

| 機能 | ページ |
|------|--------|
| レース別の分割タブ（1R〜・全レース表示）。`?race=N` / `?race=all` でも開ける | `race.html`（`result.html` には元からあり） |
| 開催ごとに「次に発走するレース」を既定で開き、タブと見出しに印を付ける。全レース表示では発走前のレースを先に、発走済みは新しい順で後ろに並べる | `race.html` |
| 既定で最新の確定レースを開き、全レース表示は新しい順 | `result.html` |
| 決まり手（逃・捲・差・マ）の色分け | `result.html` |
| 欠場選手（出走表で車番が「欠」）を本来の車番の色で「欠」と表示 | `race.html` |
| 既定の日付を端末の時計ではなく日本時間で判定（出走表は22時以降は翌日、結果は19時前は前日） | `race.html` / `result.html` |
| 固定バーの背景をダークモードでも背景色に合わせる | `race.html` / `result.html` |

「発走済み」は結果 JSON（`race_result`）に載っているかで判定しています。結果 JSON が置かれるまでは
全レースが発走前扱いになり、「次に発走するレース」は 1R になります。

本番アプリにあって静的サイトには移していないもの:
- オッズと発走時刻（取得にサーバーが要るため）
- 評価のサーバー側での出し分け（このサイトは従来どおり表示確認用の暫定実装）

## 飛びつきチャンネル（`channel.html`）

飛びつき＝**自分のラインを持たない選手が、他ラインの番手に飛びついてその位置を奪う**戦法。
その日 飛びつきが発生しそうなレースと、買い目（模範目）を掲載する画面です。

⚠️ **判定ロジックは未実装で、現在はサンプルデータを表示しています。**
画面上部に「サンプルデータ表示中」を明示しています。

### 画面の構成

- 対象日／候補レース数／開催場数
- 開催場での絞り込み（全場＋場ごとの件数）
- レースごとに、ライン・対象選手・模範目・過去の模範目成立率
- 対象選手には**オレンジの枠**、Botのもう一方の印には**黒の枠**（凡例あり）
- 模範目はコピーボタンで3行まとめてクリップボードへ

### 実データへの差し替え

`channel.html` の `SAMPLE` と同じ形の配列を実データから組み立て、`render()` に渡します。
描画側はこの形にしか依存していません。

| キー | 内容 |
|------|------|
| `place` / `raceNo` | 開催場・レース番号 |
| `lines` | 並び（ライン単位の配列） |
| `focus` / `mark` | 対象選手・Botのもう一方の印の車番 |
| `rider` | 対象選手の名前・コメント・成功率・S数 |
| `moku` | 模範目（着順ごとの車番と表記） |
| `past` | 過去データの模範目成立率 |

なお、この画面は共通ヘッダー（`KUI.mountChrome`）を使わず、「← トップ」で戻る構成です。
車番の7色とデザイントークンは共通アセットを利用しています。

## 仮ログインと会員限定表示

`login.html` は**仮のログイン画面**です。メールアドレスとパスワードに何か入力すればログインでき、
ヘッダー右上の「ログアウト」で戻ります（2026-09-27）。

| | ログイン前 | ログイン後 |
|---|---|---|
| ヘッダーの「レース結果」タブ | 出さない | 出す |
| `result.html` | 「レース結果は会員限定です」とログインボタンだけ（データを取りに行かない） | 結果を表示 |
| トップの「結果」ボタン | ログイン画面へ（ログイン後にその結果へ戻る） | 結果へ |
| `race.html` の脚評価・評価コメント | モザイク | 表示 |

- レース結果を会員限定にするかは `keirin-ui.js` の `RESULT_MEMBERS_ONLY` 1か所で切り替える
  （`false` にするとログイン前でもタブと結果が出る）
- ログイン状態は localStorage の `asilog:member`（`'1'` でログイン中）と `asilog:user`（入力したメールアドレス）。
  パスワードは確認も保存もしない
- ログイン後の戻り先（`login.html?next=`）は同じサイトの `xxx.html` だけ許す（`KUI.safeNext`）。他サイトへは飛ばさない
- `race.html?preview=member` はログインしなくても会員表示で開く（表示確認用。従来どおり）
- `race.html` にあった「ログイン前／ログイン後」の切替ボタンは、ログイン画面に置き換えたので外した
- スマホ幅（600px 以下）ではヘッダーのナビを「チャンネル／出走表／結果」の短い表記にし、ログインボタンと並んでも切れないようにしている

⚠️ このログインは localStorage による**表示確認用の暫定実装で、認証ではありません**。
静的サイトである以上クライアント側の判定は誰でも書き換えられます。
本番の出し分けは Phase 2 でサーバー側に実装し、非会員には評価データ自体を
配信しない方式へ置き換えます（`asilog-project` の `implementation-plan.md` 参照）。

レースデータは Google Cloud Storage から取得しています。ビルド不要の静的サイトで、
GitHub Pages（`main` / root）で配信しています。

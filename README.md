# ashi-public

競輪のレース情報・結果を掲載する静的サイト。

| ページ | ファイル |
|--------|---------|
| トップ | `index.html` |
| 飛びつきチャンネル | `channel.html` |
| ログイン（仮） | `login.html` |
| レース情報（出走表） | `race.html` |
| レース結果 | `result.html` |
| 運営会社 | `company/index.html` |

## 共通アセット

`channel.html` / `race.html` / `result.html` は共通デザインシステムを利用しています。

- `assets/keirin-ui.css` — 競輪専門紙ポータル調のスタイル（ネイビー基調＋赤アクセント、グレードバッジ、車番7色、高密度テーブル、固定列）
- `assets/keirin-ui.js` — 共通ユーティリティ（`KUI`）。日付操作・データ取得・バッジ描画・ライン表示・共通ヘッダー／フッター

`index.html` と `company/index.html` は独立したデザインのため、共通アセットは使っていません。

### 固定列

横スクロールする出走表・結果表では、左端の識別列を固定しています。
仕組みは `keirin-ui.css` の `.frz` にあり、列の幅と位置は各ページ側で
`--frz-left` と `min/max-width` を指定します。

| ページ | 固定する列 |
|--------|-----------|
| `race.html` | 車番・選手名 |
| `result.html` | 着順・車番・選手名 |

## 飛びつきチャンネル（`channel.html`）

飛びつき＝**自分のラインを持たない選手が、他ラインの番手に飛びついてその位置を奪う**戦法。
その日 飛びつきが発生しそうなレースと、買い目（模範目）を掲載する画面です。

⚠️ **判定ロジックは未実装で、現在はサンプルデータを表示しています。**
画面上部に「サンプルデータ表示中」を明示しています。

### 画面の構成

- 対象日／候補レース数／開催場数
- 開催場での絞り込み（全場＋場ごとの件数）
- レースごとに、ライン・対象選手・模範目・過去の模範目成立率
- 対象選手には**オレンジの枠**、Botのもう一方の印には**黒の枠**（凡例あり）
- 模範目はコピーボタンで3行まとめてクリップボードへ

### 実データへの差し替え

`channel.html` の `SAMPLE` と同じ形の配列を実データから組み立て、`render()` に渡します。
描画側はこの形にしか依存していません。

| キー | 内容 |
|------|------|
| `place` / `raceNo` | 開催場・レース番号 |
| `lines` | 並び（ライン単位の配列） |
| `focus` / `mark` | 対象選手・Botのもう一方の印の車番 |
| `rider` | 対象選手の名前・コメント・成功率・S数 |
| `moku` | 模範目（着順ごとの車番と表記） |
| `past` | 過去データの模範目成立率 |

なお、この画面は共通ヘッダー（`KUI.mountChrome`）を使わず、「← トップ」で戻る構成です。
車番の7色とデザイントークンは共通アセットを利用しています。

## ログインと会員限定表示

⚠️ **これは認証ではありません。**画面と導線を確認するための仮実装です。
静的サイトである以上クライアント側の状態は誰でも書き換えられます。
実際の認証と課金は Phase 2 でサーバー側に実装し、非会員には有料データ自体を
配信しない方式へ置き換えます（`asilog-project` の `implementation-plan.md` 参照）。

### 導線

```
トップ / 飛びつきチャンネル / レース情報
        │  「ログイン」
        ▼
   login.html?next=<戻り先>
        │  送信（どんな値でも通る）
        ▼
   戻り先のページへ。会員限定の列が表示される
```

- `race.html` の会員限定バナーからも `login.html?next=race.html` へ直接飛べます
- ログイン状態は全ページで共有され、各ページの「ログアウト」で解除できます
- `next` は**同一ディレクトリの `.html` のみ**受け付け、外部URLは `index.html` に落とします

### 実装

状態の判定は `assets/keirin-ui.js` の `KUI` に集約しています。
各ページはこれを呼ぶだけで、判定キーを直接触りません。

| API | 内容 |
|-----|------|
| `KUI.isMember()` | 会員かどうか（`?preview=member` でも有効） |
| `KUI.setMember(bool)` | ログイン／ログアウト |
| `KUI.loginUrl(next)` | 戻り先つきのログインURL |

`race.html` では、脚評価・評価コメントの列がログイン前はモザイクになります。
ログイン前は**実データを DOM に入れていません**。

## データと配信

レースデータは Google Cloud Storage から取得しています。ビルド不要の静的サイトで、
GitHub Pages（`main` / root）で配信しています。
